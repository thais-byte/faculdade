# 💻 Engenharia de Software — CEUB

Repositório dedicado à minha trajetória acadêmica no curso de **Engenharia de Software**, no Centro Universitário de Brasília (CEUB).

Aqui reúno materiais de estudo, exercícios, atividades práticas, projetos e anotações desenvolvidos ao longo da graduação, registrando meu aprendizado e minha evolução na área de tecnologia.

## 📚 Organização do repositório

Este repositório reunirá:

- **Disciplinas:** conteúdos e materiais estudados durante a graduação.
- **Exercícios:** atividades práticas e desafios de programação.
- **Projetos:** aplicações e trabalhos desenvolvidos individualmente ou em grupo.
- **Anotações:** resumos, conceitos e registros importantes para os estudos.
- **Experimentos:** testes e explorações de novas ferramentas e tecnologias.

## 🛠️ Tecnologias e conhecimentos

Esta seção será atualizada conforme eu avançar no curso e desenvolver novos projetos.

- Lógica de programação e algoritmos
- Fundamentos de desenvolvimento de software
- Banco de dados e SQL
- Engenharia de requisitos
- Arquitetura de computadores
- Outras linguagens, ferramentas e tecnologias exploradas durante a graduação

## 🎯 Objetivos

- Construir uma base sólida em programação e desenvolvimento de software.
- Aplicar os conhecimentos adquiridos em atividades práticas.
- Desenvolver projetos que demonstrem minha evolução técnica.
- Aprender continuamente e explorar novas tecnologias.
- Manter um registro organizado da minha trajetória acadêmica.

## 🌱 Em constante aprendizado

Este repositório representa uma etapa da minha jornada: um espaço para experimentar, aprender com os erros, documentar descobertas e acompanhar minha evolução como futura engenheira de software.

**Cada projeto é uma oportunidade de aprender algo novo.**
